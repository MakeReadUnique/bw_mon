复位边界

  • 观测点复位：清本点统计；祖先保留已记入的历史直到自然过期。复位期间无新增计量，释放后直接恢复向组贡献。
  • 下级组统计复位：只清本组统计；collector 继续收集、汇总、向上发布并确认消费。
  • 上级组统计复位：只影响上级自己的统计；同样继续向它的上级供数。
  • 局部复位不清注册表、不回退源序号、不重置其他消费者。下级组统计复位不冒充观测点复位覆盖。

03接口、窗口与同刻提交

先确定事件与计量字节，再按精确半开区间发布窗口。

三类接口，共用规范化记录

接口传输事件可用诊断证据
valid-onlyvalid == 1活动与静默；静默原因未知。
valid-readyvalid && readyvalid && !ready 表示握手反压。
flitv / lcrdvflitv == 1可信账本可判断信用不足；无法据此证明待发送需求。

逐传输计量

  • 固定字节量，或接入包装转换后的动态 size_bytes；每点采用一种口径。
  • 零字节传输仍是活动；已知无传输时，未用 size 的 X/Z 不污染计量。
  • 传输已知而 size 未知：事件仍计数，字节标为不完整。控制未知：保留观测缺口。

信用独立于计量

  • 每次 flitv 消耗 1 credit，每次 lcrdv 归还 1 credit。
  • 默认归还信用下一拍可用；可配置同拍可用。发送事件由 flitv 独立决定。
  • 初值、容量显式配置；异常使账本失信，确定字节仍统计。诊断不支持、未知、已知分别表达。

移动窗口：左端计入，右端排除

04流量过程与自动阶段

传输事件决定过程活动；同一条滑窗带宽序列提供阶段证据。

过程边界 ≠ 静默确认时刻

示例：首传输 80 ns，末传输 100 ns，下一采样沿 102 ns，静默阈值 Q = 30 ns。

边界示意
e2e = 过程内原始累计计量字节 ÷ [t(k_last+1) − t(k_first)]
  • 内部短暂停顿计入过程时长；末尾确认等待不计入。
  • 若 132 ns 恰好出现新传输，先确认旧过程，再开启新过程。
  • 尾周期的下一采样沿尚未出现时，时长未知，不能估算。
  • 零字节传输可启动过程、延续活动并重置静默。
  • 控制未知打断连续静默；恢复后重新累计 Q。
  • 本范围复位中断过程；成员复位不直接中断组过程。

允许重复阶段，也允许没有稳定段

未确定→爬坡→稳定→下降→稳定→ …

该顺序仅为示意；阶段不由 testbench 标签提供。低带宽甚至零带宽平台，也可能满足稳定条件。

01 / EVIDENCE

合格的新窗口结果

新发布、满窗、字节完整且不含其他过程传输。N ≥ 3，并达到最小跨度；停钟旧快照不增加证据。

02 / FIT

趋势 + 拟合残差

最近 N 点按实际发布时间等权拟合直线。delta 表示拟合总变化，rms 表示相对趋势的偏差。

03 / CONFIRM

持续 K 次 + 迟滞

候选连续满足才确认；确认后回溯到候选首次成立时刻。无效证据立即打断连续性。

例如：120 ns 首次满足候选条件，150 ns 积满 K 次。阶段边界记为 120 ns，确认时刻记为 150 ns；最终区间还要按过程边界裁剪。
展开：拟合、门槛与状态规则
yᵢ = 滑窗 GB/s，tᵢ = 实际发布时间
ŷᵢ = a + b·tᵢ
delta = b·(t_last − t_first)
rms = √mean((yᵢ − ŷᵢ)²)
候选阶段进入条件
稳定|delta| ≤ 稳定进入容差，且 rms ≤ 波动进入容差
爬坡delta ≥ 趋势门槛，且 rms ≤ 波动进入容差
下降delta ≤ −趋势门槛，且 rms ≤ 波动进入容差
未确定证据不足，或不满足可靠阶段条件
  • 容差使用“绝对项 + 相对项 × 均值”，避免除以均值。稳定退出容差较宽，趋势门槛须大于稳定退出容差。
  • N、K、最小跨度、进入 / 退出容差和 Q 均为启动前显式配置，无跨场景通用默认值。
  • 跨过程残留包括零字节事件；窗口字节为零不能证明没有上一过程残留。
  • 静默拖尾不延长过程、不强行补出下降段。边界回溯必须使用原始计数快照。

完整 e2e 的条件

  • 过程正常确认结束。
  • 首末与尾周期边界确定，字节观测完整。
  • 真实持续时间已知且大于零。
  • 缺少稳定段不使完整 e2e 失效。

质量条件分别保留

正常 / 中断 / 截断边界确定性字节完整性阶段证据成员复位覆盖

没有任何确定传输表示未形成过程，e2e 不适用；完整的零字节传输过程可具有有效的零 e2e。观察结束时未完成的过程按原因报告。

依据：自动阶段识别与全程平均带宽的边界

05统计与检查：每项结论都有自己的证据

性能预期属于具体场景。阶段判定、性能比较和辅助 hint 分别处理。

统计量来源 / 口径检查对象
稳定段带宽最终阶段区间的原始字节 ÷ 实际时长正常完成过程中，最后一个已确认稳定段
e2e过程原始字节 ÷ 实际过程时长每个满足完整条件的过程
爬坡 / 下降时间每个已确认片段的最终边界之差，单位 ns各片段独立使用该范围的同一预期
min / max、标准差、CV最终区间内发布的合格新窗口结果，按结果等权最后稳定段、整个过程；过程波动含升降与内部静默
原始字节用于稳定段带宽和 e2e；窗口序列用于波动。阶段拟合的残差 rms 与性能波动标准差是不同量。
展开：波动样本的精确选择
  • 最终区间 [a,b) 按发布时间选取 a ≤ tᵢ < b 的窗口结果；窗口本身可以覆盖同一过程的前一阶段。
  • 样本须新发布、满窗、字节完整、不混有其他过程。重叠窗口不是独立统计样本。
  • 总体标准差 σ = √mean((yᵢ−μ)²)，CV = 100 × σ / μ。min/max 至少 1 点；σ/CV 至少 2 点。
  • μ=0 时 CV 不适用；绝对波动仍可有效。不能填造 0，也不能剔除未知后宣称完整达标。

试一项带宽下限检查

仅演示性能结算公式，以下数值不是产品默认目标。

FAIL

本例绝对容差 A=0。等于有效边界算 PASS；数值不达标为 FAIL；缺少可比较结果为 WARNING。两者都继续仿真。

完整上下限公式
有效下限 = L − (A + |L| × R_pct / 100)
有效上限 = U + (A + |U| × R_pct / 100)

支持下限、上限或区间；绝对与百分比容差相加。未配置容差时 A=0、R_pct=0。

性能检查

  • PASS：有有效比较且满足允许范围。
  • FAIL：有效数值不达标。
  • WARNING：配置有误或缺少该指标所需证据。
  • 汇总优先级 FAIL > WARNING > PASS；没有检查时仅统计。最终记录只结算一次。

独立 debug hint

  • 反压与可信信用不足分别报告。
  • 显式配置阈值，ns / cycle 基准独立于统计窗口。
  • ns 跟踪真实条件变化，停钟仍计时；cycle 随周期推进。
  • 首次达到阈值提示一次，区间结束汇总；未知 / 复位打断连续性。hint 计数与性能汇总分开。

核心错误

  • 启动失败、循环 / 重叠成员。
  • 缺失、重复、倒序、错沿记录。
  • 时间、计数、序号、精确中间算术或容量不足。
  • 明确报错并终止。日志给出对象、时刻 / 期望沿及相关数值，不降级为性能 WARNING。
成员已知复位不会自动使组字节不完整；满足指标条件时继续与原组目标比较，并记录复位覆盖。目标不按活动成员数缩放，也不从下级目标相加或继承。

资源策略

  • 内部自动管理容量：预分配、增长、回收或精确无损合并由实现选择；用户无需配置历史槽数或队列深度。
