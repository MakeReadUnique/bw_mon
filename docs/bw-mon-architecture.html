到齐判断：实际沿、持久回执与生产者依赖

  • native 时钟观察器独立建立本沿预期，逐项核对 capture、held、publication、core 和输入 ACK；通知只负责唤醒，队列变空不证明已完成。
  • 上级等待直接生产者的完成凭据；本组先向上发布，再等本地 core 接纳，最后 ACK 输入。多层传播保留原始时间，无固定 delta 轮数或物理缺帧超时。
  • 源故障隔离自身及冻结拓扑中的祖先。禁用组取消自己的输入订阅；健康消费者的未读数据仍保留，取消不会伪造 ACK。
  • 停钟不创造预期沿；统计复位保持原始供数。运行期故障后的禁用是持久状态，复位不能恢复该范围。

对应实现说明：点完成与隔离 · 组完成与订阅取消 · 同刻结算。

复位边界

  • 观测点复位：清本点统计；祖先保留已记入的历史直到自然过期。复位期间无新增计量，释放后直接恢复向组贡献。
  • 下级组统计复位：只清本组统计；collector 继续收集、汇总、向上发布并确认消费。
  • 上级组统计复位：只影响上级自己的统计；同样继续向它的上级供数。
  • 局部复位不清注册表、不回退源序号、不重置其他消费者。下级组统计复位不冒充观测点复位覆盖。

三类接口，共用规范化记录

接口传输事件可用诊断证据

逐传输计量

  • 固定字节量，或接入包装转换后的动态 size_bytes；每点采用一种口径。
  • 零字节传输仍是活动；已知无传输时，未用 size 的 X/Z 不污染计量。
  • 传输已知而 size 未知：事件仍计数，字节标为不完整。控制未知：保留观测缺口。

信用独立于计量

  • 每次 flitv 消耗 1 credit，每次 lcrdv 归还 1 credit。
  • 默认归还信用下一拍可用；可配置同拍可用。发送事件由 flitv 独立决定。
  • 初值、容量显式配置；异常使账本失信，确定字节仍统计。诊断不支持、未知、已知分别表达。

移动窗口：左端计入，右端排除

04流量过程与自动阶段

传输事件决定过程活动；同一条滑窗带宽序列提供阶段证据。

过程边界 ≠ 静默确认时刻

示例：首传输 80 ns，末传输 100 ns，下一采样沿 102 ns，静默阈值 Q = 30 ns。

边界示意
e2e = 过程内原始累计计量字节 ÷ [t(k_last+1) − t(k_first)]
  • 内部短暂停顿计入过程时长；末尾确认等待不计入。
  • 若 132 ns 恰好出现新传输，先确认旧过程，再开启新过程。
  • 尾周期的下一采样沿尚未出现时，时长未知，不能估算。
  • 零字节传输可启动过程、延续活动并重置静默。
  • 控制未知打断连续静默；恢复后重新累计 Q。
  • 本范围复位中断过程；成员复位不直接中断组过程。

固定默认阶段策略 · PAIR6_R2

未确定→爬坡→稳定→下降→稳定→ …

允许重复或缺少阶段。点与组共享同一策略；阶段由原始窗口证据识别，不读取性能 checker 的参考带宽或结论。

01 / EVIDENCE

六条连续合格窗口

新发布、满窗、字节完整且不含其他过程活动。证据跨度至少 min(W,5×S)，采用原始 ns 端点或本地周期位置。

02 / PAIR FIT

相邻配对拟合

六条窗口相邻配成三个均值，按实际物理发布时间拟合趋势；原始六点残差与三个配对点残差分别计算。

03 / CONFIRM

连续两次同候选

相同候选连续两次才确认。边界回溯到候选首次成立时刻；确认时刻独立保留，再按过程边界裁剪。

EPISODE_ENABLE 默认 0；开启后，省略 PHASE_ENABLE 自动开启阶段分析，也可显式设 0 只分析过程。Q 默认 10，可显式覆盖。N、K、最小跨度和 ABS/REL 门槛已从公开参数删除。
展开：当前内部门槛与证据边界

RMS_raw = 原始六点相对拟合直线的残差
RMS_pair = 三个配对均值相对拟合直线的残差

  • 无效观测、复位与过程切换打断连续性。跨过程残留包括零字节事件，字节为零不能证明没有残留。
  • 静默拖尾不延长过程；最终裁剪保留原始确认样本和边界快照。阶段确认不表示性能检查通过。

当前控制与默认策略见中文用户手册第 8 节；实际边界 / 确认值见四个聚焦 Verdi 视图。

完整 e2e 的条件

  • 过程正常确认结束。
  • 首末与尾周期边界确定，字节观测完整。
  • 真实持续时间已知且大于零。
  • 缺少稳定段不使完整 e2e 失效。

质量条件分别保留

正常 / 中断 / 截断边界确定性字节完整性阶段证据成员复位覆盖

没有任何确定传输表示未形成过程，e2e 不适用；完整的零字节传输过程可具有有效的零 e2e。观察结束时未完成的过程按原因报告。

05统计与检查：每项结论都有自己的证据

性能预期属于具体场景。阶段判定、性能比较和辅助 hint 分别处理。

统计量来源 / 口径检查对象
稳定段带宽最终阶段区间的原始字节 ÷ 实际时长正常完成过程中，最后一个已确认稳定段
e2e过程原始字节 ÷ 实际过程时长每个满足完整条件的过程
爬坡 / 下降时间每个已确认片段的最终边界之差，单位 ns各片段独立使用该范围的同一预期
min / max、标准差、CV最终区间内发布的合格新窗口结果，按结果等权最后稳定段、整个过程；过程波动含升降与内部静默
原始字节用于稳定段带宽和 e2e；窗口序列用于波动。阶段拟合的残差 rms 与性能波动标准差是不同量。
展开：波动样本的精确选择
  • 最终区间 [a,b) 按发布时间选取 a ≤ tᵢ < b 的窗口结果；窗口本身可以覆盖同一过程的前一阶段。
  • 样本须新发布、满窗、字节完整、不混有其他过程。重叠窗口不是独立统计样本。
  • 总体标准差 σ = √mean((yᵢ−μ)²)，CV = 100 × σ / μ。min/max 至少 1 点；σ/CV 至少 2 点。
  • μ=0 时 CV 不适用；绝对波动仍可有效。不能填造 0，也不能剔除未知后宣称完整达标。

阶段分析开启即生效，无需文件或额外 checker 参数。STEADY 与性能 FAIL 可以同时成立。

BW_DEFAULT_CHECK
01 / FROZEN REFERENCE

冻结参考 B

取完整落在最终平台内、最早连续六条有效窗口的均值，跨度至少 min(W,5×S)。参考建立后不漂移，六条参考样本自身也参加检查。

02 / SUSTAINED RUN

双向持续超限

严格 |y−B| > 0.05×B 才超限；等于 5% 通过。至少两条连续新有效超限观测，原始逻辑端点跨度 ≥ W 才 FAIL；高低交替偏离仍连续。

03 / OWNERSHIP

保留平台责任

未确定区间和短新平台不能抹去旧证据。新平台交接至少两条有效观测且跨度 ≥ W；正常阶跃与升降豁免由独立阶段证据决定。

B=0、参考不足或覆盖不完整给 WARNING；可信 FAIL 在后续缺口或截断后仍保留。无效观测、回到范围内、复位或确认的排除区间打断超限连续性。参考 B 与原始字节 / 时长得到的稳定段带宽分别报告；显式目标的 PASS 不能覆盖默认 FAIL。

试一项带宽下限检查

仅演示性能结算公式，以下数值不是产品默认目标。

FAIL

本例绝对容差 A=0。等于有效边界算 PASS；数值不达标为 FAIL；缺少可比较结果为 WARNING。两者都继续仿真。

完整上下限公式
有效下限 = L − (A + |L| × R_pct / 100)
有效上限 = U + (A + |U| × R_pct / 100)

支持下限、上限或区间；绝对与百分比容差相加。未配置容差时 A=0、R_pct=0。

性能检查

  • PASS：有有效比较且满足允许范围。
  • FAIL：有效数值不达标。
  • WARNING：配置有误或缺少该指标所需证据。
  • 汇总优先级 FAIL > WARNING > PASS；没有检查时为 STATISTICS_ONLY。默认 / 显式规则分别记账，逻辑最终记录去重结算。

独立 debug hint

  • 反压与可信信用不足分别报告。
  • 显式配置阈值，ns / cycle 基准独立于统计窗口。
  • ns 跟踪真实条件变化，停钟仍计时；cycle 随周期推进。
  • 首次达到阈值提示一次，区间结束汇总；未知 / 复位打断连续性。hint 计数与性能汇总分开。

监测故障与隔离

  • 启动 / 生命周期错误：非法配置、拓扑、迟到配置等仍报 fatal。
  • 运行期可归属故障：BW_CORE_WARNING，禁用故障范围及依赖祖先；健康范围继续。
  • 共享 / 无法定位故障：保守停止全部监测，用户仿真继续。
  • 保留此前可靠结果、根因与原始回执；复位不能恢复禁用范围。监测故障与性能 WARNING 分别记录。
成员已知复位不会自动使组字节不完整；满足指标条件时继续与原组目标比较，并记录复位覆盖。目标不按活动成员数缩放，也不从下级目标相加或继承。

步骤 / 字段当前契约
