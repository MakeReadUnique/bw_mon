# bw_mon

用于 EDA 仿真验证的通用带宽监测器（bandwidth monitor）。目标是提供轻量、可复用的 SystemVerilog 模块，便于在 testbench 中观察数据传输、统计带宽并分析吞吐表现。

项目处于初始化阶段，当前包含项目目标和前期调研，尚未包含监测器实现。

## 设计方向

- **被动监测**：观察接口上的成功传输，不影响被测设计的握手和时序。
- **通用统计核心**：根据传输事件和对应字节数进行统计，协议适配逻辑独立。
- **可配置统计区间**：计划支持固定周期窗口与开始到结束的累计统计。
- **明确统计口径**：区分总线传输量与有效载荷，明确周期数、时间及带宽单位。
- **便于验证集成**：优先面向仿真使用，计划提供报告输出、接入示例和自动化测试。

## 初步开发计划

1. 定义通用统计接口、采样边界及复位、启停、清零行为。
2. 实现基础 SystemVerilog 统计模块，验证空闲、连续传输、背压和窗口边界场景。
3. 增加自定义 valid/ready、AXI-Stream 和 AXI 接口的适配与示例。
4. 增加带宽报告及 CSV 导出，明确 bytes/cycle、MB/s、GB/s 等单位及换算方式。

以上为开发计划，具体接口与功能范围将在实现前确定。
