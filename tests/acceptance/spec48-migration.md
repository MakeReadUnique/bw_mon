# Acceptance and scale reference migration

This is the reference/caller part of [default phase analysis](https://github.com/MakeReadUnique/bw_mon/issues/51), under [the integration specification](https://github.com/MakeReadUnique/bw_mon/issues/48). It is not the new complete acceptance campaign, automatic 5% checker evidence, or human waveform approval.

The public seams remain the point monitors, real named groups, member calls, setup, protocol/clock/reset inputs, public results and immutable reports. Resource observations supplement those checks. The Python references use original input events, independent leaf sets, half-open intervals and exact rational arithmetic; they never use product phase labels to choose the expected phase.

The four adopted R2 families in `tests/phase_default` and their raw-input provenance are unchanged. The worked reference vectors additionally check seventh-update confirmation, ±8% at three bandwidth scales, rejection of raw ±30% residuals hidden by pair averages, irregular physical-time fitting, and nonzero measurement origins.

The old M4/H6 topology fixture still holds one consumer from T+99ns to T+102ns. Its sixteen-parent topology, five-frame/two-control retention, fast/slow ACK positions, history pressure, and exact release assertions remain present. The removed public timeout override is not replaced. A same-time completion/cancellation/isolation equivalent belongs to the later runtime and scale tickets; `runtime_migration_pending` records this dependency. No full M1–M5/H1–H7, maximum topology, deep-history resource result or 5% checker pass is claimed here.

Migration diagnostics are stored under `/tmp/bw-mon-spec48/ticket51-references/`: red/green reference logs, public tracer sensitivity, representative acceptance FSDBs/tables, seeded ns/cycle history manifests, the pending-retention run and the 40-scope smoke run. These manifests identify consumed source hashes and distinguish working-tree diagnostics from final formal evidence. `recorded_reference_fixture.json.gz` preserves the original historical steady trace and its manifest identity solely for audit regression; `tests/scale/history_audit_paired6_fixture.json.gz` records the new small public probes separately.
